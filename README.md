# 未下课 · 五指木偶

运行 `npm start` 后打开 http://localhost:5173。视频和模型本地处理，不上传。

左手掌心控制木偶横移与有限升降，前后固定。拇指、食指、中指、无名指、小指分别控制木偶左手、右手、身体提起、左脚、右脚。保留五指校准、灵敏度、模拟动作、原场景布局与隐藏牵线表现。

右手食指左右移动控制灯横移；拇指与食指捏合后上下移动调节灯高，同时锁定水平位置。松开保留高度，恢复相对横移。没有前后移动或其他新手势。灯高范围 1～5.4，横向范围 -1.5～1.5，前后固定 0.3。横向响应受掌长影响。

捏合使用三维指尖距离除以腕部到中指指根掌长：低于 0.30 进入，高于或等于 0.45 退出。零掌长、非有限输入、丢手会清除基准。松开、退出灯高模拟、丢手重入均以当前灯位与当前手位建立相对基准。相对控制到边界后可通过重新捏合松开调整操作起点。

灯高滑杆取得模拟控制权，退出模拟按钮交回右手。恢复灯位按钮将目标明确设为初始 (1.3, 4.6, 0.3)，平滑归位。丢手超过 600 毫秒平缓归位；关闭摄像头退出模拟、清除基准并归位。吊线随灯高伸缩，灯光朝向灯下地面。保留视角、缩放和灯光开关。

## 灯具与木偶碰撞策略

优先保留左手木偶动作，灯具在 X [-1.5, 1.5]、Y [1, 5.4]、固定 Z 的范围内让位到最近安全点。逐帧从当前头、躯干、关节、手脚与肢体网格世界坐标生成包围盒，按灯罩与灯泡尺寸外扩并留余量。保留书堆避让。

先插值木偶位置与五指关节，再检查最终姿势。灯具普通让位速度上限为每秒 3 单位；来不及让位时最多尝试 13 个递减动作步长，无解退回上帧姿势。已有重叠允许一次直接安全恢复，因此启动异常重叠时可能看到位置修正。最近点搜索为有限候选枚举，没有无限迭代。最终灯位确定后统一更新灯泡、真实灯光、吊线与照射目标，不再插值覆盖。

包围盒较保守，可能在实际接触前让位或暂缓动作；不引入物理引擎。五指映射、校准、灯高模拟、隐藏牵线及布局保留。

## 家具、书本、灯具与木偶材质统一

`prop-materials.js` 使用本地 Canvas 原创图案（CC0-1.0），无外部或付费素材。桌椅使用三种轻微色差的宽刷木纹、木节与断续边缘磨损；书本保留原宽度和堆叠布局，增加分层纸页、四色封面、书签式题签及磨损；灯罩为旧绿色哑光漆面；木偶采用暖木色头部和关节、蓝灰哑光身体，保持关节对比。没有模糊滤镜或额外后处理。

仅替换材质，未改动任何几何尺寸、IK、碰撞、手势控制与相机代码。保留原程序布局的随机序列，灯泡发光与真实灯光开关联动未变。

验证：`npm run check` 通过；`verify-transitions.mjs` 灯高模拟、模式切换和光照开关检查通过；`verify-poses.mjs` 的 15 个独立模拟姿势及渲染关节检查通过，已查看近景抬手截图；`verify-collision.mjs` 458 帧无包围体重叠。前后截图为 `screenshots/material-{before,after}-{close,wide}.png`，属于不提交的本地验收产物。真人摄像头操作未重新验证。
