# 动作验收

四角色：classic、student、wooden、rigged。每角色检查 neutral、forward、back、leftStep、rightStep、lookUp、lookDown、lookLeft、lookRight、liftLook。

运行 `node verify-motion.mjs`；浏览器通过 route 读取 dist，不依赖 localhost 网络。先运行 `npm run build`。

模拟输入索引：0 左臂、1 右臂、2 整体提身、3 左腿、4 右腿、5 左脚高度、6 右脚高度、7 yaw、8 pitch。四肢范围 -1～1，高度 0～1；头部 yaw ±0.7 rad，pitch ±0.45 rad。

数值检查：输入误差 <0.02；分段骨长误差 <1e-6；脚端 y >=0.13；头部独立四元数非零，中立回零；提身相对位移 0.55。结果见 motion-results.json，截图 motion-{角色}-{动作}.png。

模拟验收与真人映射验收分开记录。真人三点校准、有符号四肢和掌面头部映射已实现，详见 live-control-acceptance.md；尚无真人摄像头实测结论。灯具使用逐帧动态包围盒回退，并非连续扫掠碰撞。


## 补充验收

已增加真实骨骼世界长度保持（误差 <1e-5）、重复施加动作后回中漂移（<1e-6 rad）、独立转头时身体矩阵不变和颈部支点保持（位置容差 0.002）、每个姿态下动态灯具安全和接触目标最近安全点检查。

分段角色根据实际脚部包围盒修正 IK，骨骼模型固定初始高度增加 0.065；后者依据当前资源中立最低顶点 -0.004 测量，避免动态抬升造成头部与身体耦合。更换骨骼资源时必须重新测量该偏移。骨骼变形顶点最低高度纳入检查。

碰撞检查仍是离散姿态包围盒，不构成任意高速动作的连续碰撞证明；模拟验收未覆盖真人手势映射。
